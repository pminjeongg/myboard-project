# 일상 공유 게시판

Node.js, Express, MongoDB로 만든 게시판과 미니 테트리스 웹사이트입니다.

## 기능
- 게시글 작성 / 삭제 / 검색 / 페이지 이동
- 미니 테트리스 게임

## 사용 기술
- Node.js, Express
- MongoDB (Mongoose)
- HTML, CSS, JavaScript

## 실행 방법
1. 패키지 설치
   npm install
2. 프로젝트 폴더에 `.env` 파일을 만들고 아래처럼 입력
   MONGO_URI=내 MongoDB 접속 주소
3. 서버 실행
   node server
4. 브라우저에서 http://localhost:3000 접속
